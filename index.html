Accesibilidad y metodología POUR

El diseño busca que diferentes personas puedan utilizar el sitio de manera sencilla y comprensible.

01

Perceptible

La información se presenta mediante textos claros, botones visibles, iconos y suficiente contraste entre el contenido y el fondo.

02

Operable

La navegación utiliza botones grandes y fáciles de identificar. Las funciones principales pueden utilizarse mediante teclado y diferentes dispositivos.

03

Comprensible

La página utiliza lenguaje sencillo, instrucciones directas y una estructura organizada para que el usuario pueda entender qué hacer.

04

Robusto

El sitio utiliza HTML semántico, botones reales y una estructura adaptable a diferentes tamaños de pantalla y tecnologías de asistencia.
